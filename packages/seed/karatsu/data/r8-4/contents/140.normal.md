## どんな議案？

市が運営する **モーターボート競走事業** の **令和7年度の決算** と、**残った利益の使いみち（利益処分）** を決める議案です。
水道や病院などの市の事業（公営企業）は、ふだんの会計とは別に、企業と同じような会計（利益・損失を計算する方式）でお金を管理しています。決算は、その1年間（令和7年4月～令和8年3月）の結果をまとめたもので、議会が **「認定」** するかどうかを決めます。
利益の使いみちは、議会が「可決」するかどうかを決めます。

## 売上と利用者

- 年間 **180日** 開催し、舟券の総売上は **約916億588万円**（前年度の98.8％）
- 売上のうち電話投票が約770億4,400万円
- 本場の入場者は13万7,235人（1日平均762人）

## 収入と支出

| | 金額 |
|---|---|
| 営業収益（消費税抜き） | 約952億1,699万円 |
| 営業費用（消費税抜き） | 約874億2,673万円 |
| 営業利益 | 約77億9,026万円 |
| **当年度の純利益** | **約57億9,906万円** |

## 利益の使いみち

純利益などを合わせた **未処分利益剰余金は約92億8,106万円** です。このうち約86億2,662万円を次のように使います。

| 使いみち | 金額 |
|---|---|
| **市の一般会計への繰出し** | **35億円** |
| 建設改良積立金 | 20億円 |
| 利益積立金 | 1億円 |
| 自己資本金への組入れ | 約30億2,662万円 |

残りの約6億5,444万円は翌年度に繰り越します。

## 結果

**10月13日の本会議で、利益の処分は原案どおり可決、決算は認定されました。**
