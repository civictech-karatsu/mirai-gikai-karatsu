## どんな議案？

唐津市名護屋城茶苑「海月」の **使用料** と **利用のルール** を変える条例改正です。
市は令和9年4月に、文化施設・体育施設・観光施設など100施設の使用料をまとめて見直します。この議案はそのうちの1つです。

## 何が変わるの？

### 入園料は無料に

| | いま | 改正後 |
|---|---|---|
| 個人：大人など | 210円 | **無料** |
| 個人：高校生など | 150円 | **無料** |
| 団体：大人 | 150円 | **無料** |
| 団体：高校生など | 100円 | **無料** |

### 茶室・茶屋の使用料は1時間ごとに

| | いま：9時～12時 | いま：12時～17時 | 改正後：1時間あたり |
|---|---|---|---|
| 茶室棟 小間 | 3,140円 | 4,190円 | **1,370円** |
| 茶室棟 8畳 | 2,610円 | 3,660円 | **1,170円** |
| 茶屋棟 10畳 | 2,410円 | 3,450円 | **1,090円** |
| 茶屋棟 9畳 | 2,090円 | 2,930円 | **940円** |
| 茶屋棟 6畳 | 1,780円 | 2,410円 | **780円** |
| 茶屋棟 立礼席 | 1,460円 | 2,090円 | **660円** |

- 午後5時以降は2割5分増し
- 営利目的の場合や、入場料・会費などを取る場合は2倍

### 施設の目的とルールの整理
- 施設の目的を「茶の湯文化を通じた交流の促進と文化活動の醸成を図り、市民文化の発展向上に役立てる」と書き改めます
- 利用や入館を断れる場合、利用する権利の譲渡の禁止、原状回復、損害賠償などのルールを整理します

## いつから？

**令和9年（2027年）4月1日** から。
それより前（条例の公布日より前）に利用の許可を受けた分は、いまの料金のままです。

## 結果

**9月25日の本会議で、原案どおり可決されました。**
