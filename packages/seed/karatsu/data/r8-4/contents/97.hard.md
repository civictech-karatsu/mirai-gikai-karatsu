---
title: 議案第97号 唐津市民会館条例制定について
summary: 唐津市民会館（西城内6番33号）の設置・管理・使用料・入場料・指定管理者制度等を定める条例の制定。曳山展示場を会館の施設とし、附則で唐津市曳山展示場条例を令和9年4月1日に廃止する。令和8年9月25日原案可決。
---
## 提案理由

唐津市民会館の設置に伴い制定するもの（担当：新市民会館準備課）。

## 条例の構成

| 条 | 内容 |
|---|---|
| 第1条（設置） | 市民の自主的な文化芸術活動の場の提供、文化交流による賑わいの創出、観光交流拠点としての伝統文化の保存・継承・発信 |
| 第2条（名称・位置） | 唐津市民会館／唐津市西城内6番33号 |
| 第3条（施設） | ホール及びその附属施設、曳山展示場、その他附属施設 |
| 第4〜6条 | ホール等の利用許可制、利用制限、利用権の譲渡・転貸の禁止 |
| 第7条（使用料） | 別表第1の使用料を前納。特別の理由による減免・返還 |
| 第8条（入場料） | 曳山展示場の入場者は別表第2の入場料を前納 |
| 第9〜12条 | 原状回復、損害賠償、立入検査、免責 |
| 第13〜16条 | 指定管理者による管理、業務範囲、個人情報の取扱い、利用料金制（別表の額の範囲内で市長の承認を得て指定管理者が定める） |

## 別表第1：使用料（抜粋）

### 大ホール（午前9時〜午後10時の全日利用）
| 区分 | 平日 | 休日等 |
|---|---|---|
| 入場料等を徴収しない場合 | 113,870円 | 130,130円 |
| 入場料等の最高額が3,000円以下 | 162,690円 | 195,220円 |
| 入場料等の最高額が3,000円超 | 244,030円 | 292,820円 |

市民等が営利目的で利用する場合と、市民等以外が利用する場合は、入場料等の有無にかかわらず「3,000円超」の区分を適用する。

### 小ホール・附属施設等（1時間当たり）
小ホール1,160円、大楽屋440円、中楽屋170円、活動室1 290円、活動室2 260円。市民等の営利目的利用・市民等以外の利用は10割加算。

### グランドピアノ（1日1回当たり）
フルコンサートピアノ6,000円、セミコンサートピアノ4,000円（調律費は利用者負担）。

## 別表第2：曳山展示場入場料

| 区分 | 市内居住者 | 市外居住者 |
|---|---|---|
| 一般（15歳以上、中高生除く） | 500円（団体400円） | 1,000円（団体800円） |
| 小・中学生及び高校生 | 250円（団体200円） | 500円（団体400円） |
| 未就学児 | 無料 | 無料 |
| 年間入場料（一般） | 2,500円 | 5,000円 |
| 年間入場料（小中高生） | 1,250円 | 2,500円 |

団体は20人以上。

## 附則

- 施行日は規則で定める日。ただし唐津市条例の廃止に関する条例の改正（唐津市曳山展示場条例〈令和2年条例第46号〉の廃止）は令和9年4月1日施行
- 施行前でも利用許可等の準備行為ができる

## 議決結果

- 提出：令和8年9月1日
- 議決：令和8年9月25日 **原案可決**
