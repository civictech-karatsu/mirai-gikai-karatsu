## どんな議案？

市のふだんの会計である **一般会計** の、**令和7年度の決算** です。
決算は、市が1年間（令和7年4月～令和8年3月）に実際に集めたお金と使ったお金をまとめたものです。議会がその内容を確認して **「認定」** するかどうかを決めます。

## 収入と支出

| | 金額 |
|---|---|
| 収入（歳入総額） | **約907億6,153万円** |
| 支出（歳出総額） | **約884億3,917万円** |
| 差し引き | 約23億2,236万円 |
| うち翌年度に繰り越して使う財源 | 約8億2,140万円 |
| **実質収支（実質的な黒字）** | **約15億96万円** |

実質収支のうち8億円は、地方自治法の規定により基金に積み立てられます。

## 市が説明するおもな取り組み

市の「主要施策成果説明書」では、令和7年度のおもな取り組みとして次のものが挙げられています。

- 市立小中学校の **給食費の無償化** と、給食1食あたりの単価の引き上げ
- 松浦河畔公園や鳴神公園の再整備
- 交通事業者が従業員の第二種運転免許の取得費用を負担する取り組みへの支援、タクシーの配車アプリの導入促進
- 離島住民の通院助成制度の拡充、老朽危険空き家の除却の推進
- 燃油・飼料価格の高騰の影響を受けている施設園芸農業者・漁業者・畜産農家への支援金
- ふるさと寄附金で5年連続50億円以上を受け入れ
- 新市誕生20周年記念事業
- 令和5年から令和7年にかけての豪雨などによる災害からの復旧

## 結果

**10月13日の本会議で、認定されました。**
