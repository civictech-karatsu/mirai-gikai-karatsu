## どんな議案？

唐津市呼子交流促進施設の **使用料** を変える条例改正です。
市は令和9年4月に、文化施設・体育施設・観光施設など100施設の使用料をまとめて見直します。この議案はそのうちの1つです。

## 何が変わるの？

| | いま | 改正後 |
|---|---|---|
| 宿泊：大人（1泊1人） | 3,080円 | **4,620円** |
| 宿泊：小学生（1泊1人） | 2,530円 | **3,790円** |
| 宿泊：就学前の子ども（1泊1人） | 1,650円 | **2,470円** |
| 休憩：大人（1人） | 550円 | **820円** |
| 休憩：小学生（1人） | 330円 | **490円** |
| 休憩：就学前の子ども | 無料 | 無料 |
| 大研修室 | 740円 | **1,110円** |
| 小研修室 | 370円 | **550円** |

## いつから？

**令和9年（2027年）4月1日** から。
それより前（条例の公布日より前）に利用の許可を受けた分は、いまの料金のままです。

## 結果

**9月25日の本会議で、原案どおり可決されました。**
