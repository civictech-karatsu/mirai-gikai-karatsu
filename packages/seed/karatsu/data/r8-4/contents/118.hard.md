title: 議案第118号 唐津市自転車等の放置防止等に関する条例制定について
summary: 公共の場所における自転車・原動機付自転車の放置防止と市管理自転車等駐車場の適正利用確保のため、関係者の責務、放置自転車等への指導・移動・保管、長期駐車自転車等の移動・保管、告示後の廃棄等の処分を定める条例の制定。令和9年4月1日施行。令和8年9月25日原案可決。
---
## 提案理由

自転車等の放置防止等に関し必要な事項を定めるもの（担当：都市計画課）。

## 条例の構成

| 条 | 内容 |
|---|---|
| 第1条（目的） | 公共の場所における自転車等の放置防止、市管理自転車等駐車場の適正な利用の確保により、良好な生活環境の確保と都市の美観の維持を図る |
| 第2条（定義） | 自転車等＝自転車及び原動機付自転車。公共の場所＝道路、公園その他公共の用に供する場所で市が管理するもの。放置自転車等＝自転車等駐車場以外の公共の場所に置かれ、利用者が離れていて直ちに移動できない状態のもの。長期駐車自転車等＝市管理自転車等駐車場に規則で定める期間を超えて継続駐車等され、適正な利用・管理に支障を及ぼしているもの |
| 第3条 | 市の責務（必要な施策の実施） |
| 第4条 | 利用者等の責務（放置の禁止、駐車場の適正利用、施策への協力） |
| 第5条 | 自転車小売業者の責務（防犯登録の勧奨、施策への協力） |
| 第6条 | 鉄道事業者・一般乗合旅客自動車運送事業者の責務（自転車等駐車場の設置努力） |
| 第7条 | 大量駐車需要を生じさせる施設（公共・商業・娯楽施設等）の設置者の責務（駐車場の設置努力） |
| 第8条 | 放置自転車等に対する措置：市長は生活環境が阻害されていると認めるとき利用者等を指導でき、規則で定める期間経過後も放置されているときは移動・保管できる |
| 第9条 | 長期駐車自転車等に対する措置：市長は移動・保管できる |
| 第10条 | 保管した自転車等の告示、返還措置。告示の日から規則で定める期間を経過しても返還できないときは廃棄等の処分ができる |
| 第11条 | 委任（規則） |

指導後の待機期間、長期駐車の判定期間、告示後の保管期間はいずれも規則に委任されている。
