## どんな議案？

**唐津市市民病院きたはた** の、**令和7年度の決算** です。
水道や病院などの市の事業（公営企業）は、ふだんの会計とは別に、企業と同じような会計（利益・損失を計算する方式）でお金を管理しています。決算は、その1年間（令和7年4月～令和8年3月）の結果をまとめたもので、議会が **「認定」** するかどうかを決めます。

## 収入と支出（消費税込み）

| | 収入 | 支出 |
|---|---|---|
| 日々の事業（収益的収支） | 約6億9,898万円 | 約6億9,553万円 |
| 施設の整備など（資本的収支） | 約2,230万円 | 約5,520万円 |

## 利益と損失

| | 金額 |
|---|---|
| 医業収益（入院・外来など） | 約5億6,737万円 |
| 医業費用（給与・材料費など） | 約6億7,116万円 |
| **医業損失** | **約1億379万円** |
| 医業外収益（ほかの会計からの負担金・補助金など） | 約1億2,848万円 |
| 医業外費用 | 約2,270万円 |
| 経常利益 | 約198万円 |
| **当年度の純利益** | **約53万円** |

医業外収益のうち、市のほかの会計からの負担金（他会計負担金）は9,407万6千円です。医業収益にも他会計負担金3,968万8千円が含まれています。

当年度末の未処分利益剰余金は約3億2,821万円です。

## 結果

**10月13日の本会議で、認定されました。**
