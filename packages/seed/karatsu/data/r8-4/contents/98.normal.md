## どんな議案？

市の都市公園にある有料の運動施設の **使用料** を変える条例改正です。
市は令和9年4月に、文化施設・体育施設・観光施設など100施設の使用料をまとめて見直します。この議案はそのうちの1つです。

「一般」は15歳以上で、中学生・高校生ではない人です。

## 何が変わるの？（1時間あたり）

### 文化体育館

| | いま | 改正後 |
|---|---|---|
| 競技場 一般・全面 | 1,590円 | **2,380円** |
| 競技場 一般・半面 | 790円 | **1,190円** |
| 競技場 生徒・児童・全面 | 790円 | **1,190円** |
| 競技場 生徒・児童・半面 | 390円 | **590円** |
| 競技場の冷暖房 | 15,990円 | **18,420円** |
| 柔道場・剣道場 一般 | 790円 | **810円** |
| 弓道場 一般 | 790円 | **1,180円** |
| トレーニング室 個人 一般 | 110円 | **150円** |
| トレーニング室 個人 生徒・児童 | 50円 | **70円** |

文化ホールの冷暖房料金（1,280円）は、ホールの使用料に含まれるようになります。文化ホールと会議室の使用料は変わりません。

| ラグビー・サッカー場 生徒・児童・全面 | 1,550円 | **1,650円** |
| 庭球場の壁打ちコート 一般 | 110円 | **160円** |

### 料金の決まりごと
- 市外の人や、**市外を拠点とする団体** は2倍の料金です（いまは「団体」と書かれている部分を「市外を拠点とする団体」に改めます）
- 物の販売・宣伝のために使う場合や入場料を取る場合は5倍ですが、**夜間照明と冷暖房の料金は5倍の対象から外れます**
- 個人利用の回数券として「10円券の12枚つづり（100円）」を加えます
- 市の案内では、令和8年度までに買った個人利用の回数券は、差額を払えば令和9年4月以降も使えるとされています

## いつから？

**令和9年（2027年）4月1日** から。
それより前（条例の公布日より前）に利用の許可を受けた分は、いまの料金のままです。

## 結果

**9月25日の本会議で、原案どおり可決されました。**
