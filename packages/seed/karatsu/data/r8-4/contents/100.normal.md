## どんな議案？

唐津市高齢者ふれあい会館の **使用料** を変える条例改正です。
市は令和9年4月に、文化施設・体育施設・観光施設など100施設の使用料をまとめて見直します。この議案はそのうちの1つです。

## 何が変わるの？

| | いま | 改正後 |
|---|---|---|
| ホール（1時間） | 1,960円 | **4,570円** |
| 研修室1（1時間） | 1,350円 | **2,020円** |
| 研修室2（1時間） | 660円 | **990円** |
| 研修室3（1時間） | 850円 | **1,270円** |
| 浴場（1人1回） | 210円 | **260円** |
| セミコンサートピアノA（1日） | なし | **3,320円** |
| セミコンサートピアノB（1日） | なし | **2,410円** |

- 営利目的で使う場合、入場料や会費などを取る場合、市民等（市内に住む人や、市内を主な活動拠点とする団体）以外が使う場合は **2倍** の料金になります
- ピアノの調律代は利用者の負担です

## いつから？

**令和9年（2027年）4月1日** から。
それより前（条例の公布日より前）に利用の許可を受けた分は、いまの料金のままです。

## 結果

**9月25日の本会議で、原案どおり可決されました。**
